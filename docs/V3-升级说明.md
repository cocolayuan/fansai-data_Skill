# FansAI 数据中台 V3 升级说明

V3以线上V2.1为基线，将本轮审批中心的已确认迭代合并到同一平台skill中。V2.1源目录与打包文件保留，V3可独立使用；不是只交付一个图标补丁，也不表示线上产品已经部署V3。

## 关键信息

| 主题 | V3落地 |
|---|---|
| 页面配色 | 原有薄荷弥散全局底色保留；只有审批弹窗底层用极浅灰蓝绿，前景模块纯白 |
| 发起审批 | 居中弹窗、九类白卡、较大间距、恢复真实功能说明；侧栏发起按钮略弱化 |
| 图标升级 | V15静态融合像素展示库，九业务45个SVG/PNG导出；用于大面积分类和重点展示，小功能icon仍沿用IconPark |
| 详情资料 | 移除微小展示图贴片，业务标题加大加粗，分区与轻行面结合，字段完整 |
| 下拉与tag | 选项从线性框改成面性填充；焦点、选中勾、键盘、浮层自动翻转与边界处理保留 |
| 审批按钮 | 先在同事选择旁确认转交，底部工作流动作另层；当前步骤只有一个强主操作 |
| 评论与附件 | 阅读层次简化，白色输入和附件区；资料以文档示意呈现，回复/预览/取消/提交行为明确 |
| 侧栏与表格 | 目录约45px单行，计数紧凑；表格轻水平线与浅行面结合，标题/金额/元信息分级 |

## 继续继承

数据真实性、缺失值规则、完整业务字段、语义状态色、36px页面边距、单层背景、等高面板、图表选型、主从记录、局部时间轴、固定操作列、头像规则与可编辑交付要求都保留。V3明确修改的配方已同步更新，不只是在旧规则后追加相反要求。

九类图标来自用户提供的“FansAI-融合像素图标-静态版”，源标识V15。08外包付款为蓝灰配色。原始图面保留；完整资源路径、尺寸和校验值见[目录](../fansai-data-system_Skill_V3/assets/catalog.json)。这批资产不含独立Logo本体，因此V3只规定品牌展示图标阶段，不声称整个branding已重做。

## 开发与使用

- 导入[完整V3包](../fansai-data-system_Skill_V3.skill)，或将源目录复制为技能目录`fansai-data-system-v3`；调用`$fansai-data-system-v3`。
- 一个页面选定一个平台版本。线上维护可继续指定V2.1；V3任务不要同时加载V2.1并把两套冲突默认混用。
- V3已含图标规范和资产，平台任务无需另外加载`fansai-brand-display-icons`；该独立skill仍可用于单纯图标库任务。
- 本次不批量重写历史Demo或旧审批HTML；旧HTML仍可用于业务与交互交接，使用V3实现时按新规范迁移图标、尺寸及组件。
- HTML高保真是前端需求与交互参考；开发仍需接入真实权限、数据、审批流、上传接口和异常处理。没有后端的页面维持示例标记。

## 边界与检查

横图最小240×96 CSS px、方图最小128px是V3新增使用默认，不是源资产已验证所有设备的结论；实际页面仍需检查辨识度。新大图所需空间优先通过减少列数解决，不裁切图面或压缩功能说明。

源码中的历史HTML范例原样继承，未声称已升级为V3。新的下拉实现与品牌资源可独立复用；继承规则和新增规则以V3主入口列出的优先级执行。
